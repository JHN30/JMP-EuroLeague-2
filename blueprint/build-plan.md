# Build Plan

This plan covers the PERN rebuild of JMP Euroleague. Phase 1 supports only EuroLeague seasons `E2025` (2025-26) and `E2026` (2026-27). Build every feature against PostgreSQL data exposed through the TypeScript API; do not reuse the old MongoDB models or rating-based logic.

Scaffolding, shared layout, design tokens, database connection setup, and deployment configuration are pre-build work rather than product features.

## Guideline deviations

`UI-UX.md` is followed except where this project's own constraints override it. Record the
reason alongside the change, not only here.

- **No backdrop blur.** The guideline's panel uses a translucent fill with a backdrop blur. Section 7 of the project plan rules blur out after measured performance problems in the previous interface, so panels use an opaque fill and take their hierarchy from border and background delta alone.
- **Chart.js stays.** The guideline hand-rolls every chart and uses no charting library. We keep Chart.js where it is already in use and apply the guideline's conventions to it instead; see 15g.
- **One competition, two seasons.** The guideline describes a EuroCup toggle and an archive reaching back to 2006-07. Phase 1 is EuroLeague `E2025` and `E2026`, so there is no competition selector, "all-time" means archive-to-date, and career history is season-by-season.
- **No shot or event data.** Shot charts, the shooting studio, play-by-play, venue, attendance, and officials have no source columns. They are handled as coverage entries and empty states under feature 16, never as fabricated values.
- **Product naming.** The guideline is written for a differently named demo product. Its naming, brand mark, and copy examples are illustrative only.
